# Supported shells

| Shell | Status | Notes |
|-------|--------|-------|
| POSIX (bash/sh) | Incremental | Pipes, chains, redirections, quotes, env vars, substitutions. |
| PowerShell | Incremental | Cmdlets, pipes, redirections, variables. |
| Windows CMD | Incremental | Commands, pipes, redirections, %VAR%. |

No shell is claimed fully compatible. Unsupported syntax yields partial analysis.
